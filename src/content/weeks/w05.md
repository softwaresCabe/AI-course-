## 5.1 The transformer at a glance

"Attention Is All You Need" (Vaswani et al., 2017) introduced the **transformer**: an architecture built entirely from attention and feed-forward layers, with no recurrence. The original was an **encoder–decoder** for translation. Three families descend from it:

- **Encoder-only** (BERT): bidirectional attention, trained with masked-token prediction; great for classification and embeddings.
- **Decoder-only** (GPT-2/3, LLaMA, Mistral, DeepSeek and, as far as is publicly known, most frontier LLMs): causal attention, next-token prediction; the default for generative models.
- **Encoder–decoder** (T5, original transformer): encoder reads input, decoder generates with cross-attention to it.

This week focuses on the **decoder-only** model you'll build in the lab.

## 5.2 The forward pass, end to end

```
tokens (B, T)
  → token embedding (B, T, d)  [+ positional information]
  → N × TransformerBlock
  → final norm
  → unembedding / LM head  (B, T, vocab)  → logits
  → softmax → p(next token)
```

A modern **pre-norm** block:

```
x = x + Attention( Norm(x) )      # tokens exchange information
x = x + FFN( Norm(x) )            # each token processed independently
```

Mental model: the **residual stream** `x` is a running "working memory" per token. Attention layers *move* information between positions; FFN (MLP) layers *transform* information within a position (and act as a large key–value memory for facts). Each layer reads from and writes back into the stream additively.

**Pre-norm vs post-norm**: the original paper normalized *after* the residual add (post-norm). Most modern LLMs use **pre-norm** (normalize the input to each sublayer), which trains more stably at depth.

## 5.3 Multi-head attention

Instead of one attention with `d`-dimensional keys, split into `h` heads of size `d_k = d/h`, run attention independently in each, concatenate, and project with `W_O`:

```
headᵢ = Attention(X W_Qᵢ, X W_Kᵢ, X W_Vᵢ)
MHA(X) = Concat(head₁…head_h) W_O
```

Different heads learn different relations (previous-token, syntactic dependencies, copying). Interpretability research found **induction heads** — circuits that look for an earlier occurrence of the current token and copy what followed it — a mechanism behind in-context learning.

Parameter count per attention layer: `W_Q, W_K, W_V, W_O` are each `d×d` → **4d²**.

Inference-friendly variants:
- **Multi-Query Attention (MQA)**: all heads share one K and V.
- **Grouped-Query Attention (GQA)**: groups of query heads share K/V. Shrinks the **KV cache** (Week 8) a lot with little quality loss; widely used in modern open models.

## 5.4 The feed-forward network

Applied to each position independently:

```
FFN(x) = W₂ · φ(W₁ x)       # W₁: d → d_ff, W₂: d_ff → d, classically d_ff = 4d
```

Parameters ≈ `2 · d · d_ff = 8d²` for d_ff = 4d. With **SwiGLU**, there are three matrices; d_ff is often set to ~(8/3)d to keep the parameter count similar.

So a block has ≈ **12d²** parameters (4d² attention + 8d² FFN). Total for the stack: `≈ 12 · N_layers · d²` plus embeddings `vocab · d`. GPT-2 small: d = 768, N = 12 → 12·12·768² ≈ 85M in blocks + ~38.6M embeddings ≈ 124M. ✔

**Mixture-of-Experts (MoE)** replaces the single FFN with many expert FFNs and a **router** that sends each token to the top-k (e.g. 2) of them. Total parameters grow massively while *active* parameters (and FLOPs) per token stay modest. Many frontier and open models are MoE.

## 5.5 Positional information

Attention is **permutation-equivariant** — without position info, "dog bites man" = "man bites dog". Approaches:
- **Sinusoidal absolute** encodings (original paper), added to embeddings.
- **Learned absolute** position embeddings (GPT-2) — fixed maximum length.
- **RoPE (Rotary Position Embedding)**: rotate query and key vectors by an angle proportional to position, so `qᵢ · kⱼ` depends on the *relative* offset `i − j`. Used in LLaMA and most modern LLMs; context can be extended later by rescaling frequencies (e.g. position interpolation, YaRN).
- **ALiBi**: add a linear distance penalty to attention scores.

## 5.6 Output, loss and training in parallel

The LM head maps each position's final vector to vocabulary logits. Training uses cross-entropy at **every position simultaneously**: input `tokens[:, :-1]`, targets `tokens[:, 1:]`. One forward pass over a 4,096-token sequence yields 4,095 training signals — a key reason transformers are so data- and compute-efficient to train compared with RNNs.

## 5.7 Why transformers won

1. **Parallelism**: all positions processed at once in training → excellent GPU utilization.
2. **Direct long-range paths**: any token reaches any other in one hop (vs. O(n) hops in RNNs).
3. **Scalability**: performance improves predictably with more parameters, data and compute (Week 6).
4. **Generality**: the same block works for text, images (ViT), audio, video, proteins and actions — the basis of today's multimodal models.

Active research alternatives — **state-space models** (Mamba), linear attention, hybrids — aim to beat the O(n²) cost for very long contexts. Knowing the trade-offs is part of reading the field.
